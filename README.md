# PyAnimate

PyAnimate is a browser-based Python learning playground focused on animated explanations, visual execution, and progressive skill tracks.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Monaco Editor

## Run locally

```bash
npm install
npm run dev
```

## MVP direction

- Animated landing page with level-based paths
- Browser playground shell for Python execution concepts
- Monaco-backed editing surface for lesson code
- Visual memory and step-by-step execution model
- Future Pyodide integration for real Python execution in-browser
